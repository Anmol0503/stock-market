# UI tests for The Briefing (`dashboard/reels/`)

These tests render the real phone app in Chrome and check it, so UI changes never ship unseen.

```bash
cd tests/ui
npm install                 # playwright-core only (uses your installed Google Chrome, no browser download)
node shoot.mjs              # screenshots + overflow check, all phone sizes, dark + light
node flows.mjs              # interaction flows (jump links, explainer, quiz, Play all, calendar, SW, …)
```

Requirements: Node 20+, Google Chrome, `python3`, and `ffmpeg` (for the two generated test reels).
Overrides: `CHROME=/path/to/chrome`, `FFMPEG=/path/to/ffmpeg`. `npx` isn't needed. If `node`/`npm` aren't on
your PATH, call them by full path.

## How it works

Every run builds a throwaway site in the system temp folder, serves it with `python3 -m http.server`, and
deletes it afterwards. It contains:

- `dashboard/reels/`: the app under test (a copy of the working tree).
- `dashboard/digest/`: the real old-digest archive.
- `dashboard/briefing/2026-11-03.json`, `index.json` and `videos/2026-11-03.json`: the fixtures in
  `tests/fixtures/briefing/`.
- `dashboard/media/2026-11-03/s1-…mp4`, `s2-…mp4` and their `.jpg` posters: generated by ffmpeg and cached in
  `out/.media/`.

**The real `dashboard/briefing/` is never read or written.** The app's clock is pinned with
`?now=2026-11-03T07:10` (IST), which makes the running-late banner and reel polling deterministic.

## `shoot.mjs`

Viewports are run with `isMobile`, touch and `deviceScaleFactor: 2`, in dark and light:

| Viewport | Device | Overflow target |
| --- | --- | --- |
| 390×664 | iPhone 14 in Safari | 0 |
| 375×548 | iPhone SE in Safari | ≤ 1 |
| 412×780 | Large Android | 0 |
| 390×844 | Full screen | Reported, target 0 |

For every card it walks each text line. A line counts as an **overflow** if it is cut by an ancestor's
overflow, clipped by the viewport, or sits on a card designed to fit (`.card.fit`) that needs to scroll.
These are reported separately and are not failures:

- Clamped text: the story headline, question and dek are clamped on purpose.
- Intended scrolling: long briefs scroll inside their card, with a "More" hint.
- Tap targets under 44px.

Any console error fails the run.

Output is written to `out/`:

- `out/<w>x<h>-<theme>/*.png`: cover, before-you-scroll, story-video, story-no-video, story-stale-no-video,
  section-intro, section-brief, quiet, also, quiz-answered, developing, caught-up, explainer-top / -scrolled /
  -extras / -sources, calendar, display, play-all.
- `out/_sheet-<w>x<h>-<theme>.png`: a contact sheet of the key screens, for a quick look.
- `out/digest-390x664.png`: the old-digest archive page with its "New: The Briefing" link.
- `out/report.json`: every issue, clamp, scrolling brief and small tap target.

Set `ONLY=390x664` or `THEMES=dark` to run a subset.

## `flows.mjs`

1. "Before you scroll" rows jump to the right story card or brief.
2. The explainer opens from the card button and closes with ✕ and with Back. The reel pauses under it.
3. Deep links work: `#<date>/<storyId>` opens the explainer over its card, and `#<date>/<section>` lands on
   the section.
4. Quiz: an answer reveals the right/wrong colours and the why. A second tap is ignored and nothing is saved.
5. Play all: it shows segmented bars, auto-advances on `ended`, closes after the last reel, and
   "Read explainer" works.
6. A stale reel (`reel_hash` mismatch, s3) is never requested; its card shows the gradient hero.
7. Calendar: briefing days are marked, partial days get an amber ring, and grey days open
   `digest.html#<date>`.
8. The running-late banner shows at 07:00 IST the day after the latest edition; it doesn't show before
   06:45 or on the edition's own day.
9. Polling: a reel that appears later is attached to off-screen cards only. The card being read never
   changes under you.
10. A broken `src` falls back to `fallback_src`. If both fail, the card shows the gradient hero.
11. Service worker: it caches the shell and `digest.html`, never handles `.mp4`, and an offline reload still
    shows the edition.
12. Refresh loads a newer edition and clears the running-late banner.
13. A partial edition shows its status banner and notes. Screenshots go to `out/flows/`.
14. When there is no index yet, a friendly empty state links to the old digest.
15. Watch → Read explainer → close leaves exactly one pause/resume, and the reel plays again.
